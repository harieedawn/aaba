Thư mục này để bạn tự bỏ file font Google Sans vào (app không nhúng sẵn font).
Biến thể (variable) — ưu tiên: gsans-vf.woff2, hoặc gsans-vf.woff, hoặc gsans-vf.ttf
Tĩnh (static) — dự phòng: gsans-400.woff2, gsans-500.woff2, gsans-700.woff2 (hoặc đuôi .ttf)
Không có file nào thì app dùng font hệ thống, vẫn hiển thị bình thường.
Giữ nguyên tên file như trên, không cần sửa code hay CSS.
Giấy phép: SIL OFL 1.1 — nhớ kèm file OFL.txt cùng với font khi phát hành.
