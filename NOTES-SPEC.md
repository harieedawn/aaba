# NOTES-SPEC (final, after stage 2)
Vanilla ES modules, no build, Vietnamese UI (label "Notes" is English). Route `#/notes`, nav item after Tổng kết, icon `note`.
## Files
css/notes.css · js/notes/{dates,layout,subjects,data,board,sheet,calendar,agenda,index}.js · js/data/notestore.js (pass-through; store.js re-exports noteWatch/noteRange/noteSet/noteRemove) · notes.selftest.mjs (`node`, dates+layout+AA contrast).
Edited: app.js (NAV + `ghi-li` class), router.js, session.js, icons.js, adapter.firebase/local, store.js, seed.js, index.html, firestore.rules.
## Data model (ids 'n_'+base36 time+4 chars; date = Vietnam 'YYYY-MM-DD')
`notes`: date, subject, title(1-80), body(0-1000), color '#RRGGBB', by, byName, at(ms), upd(ms). `pnotes`: same minus by/byName, plus owner(uid), slot(int>=0).
Subjects: toan van anh ly hoa sinh su gdqp tin khac (default colour hex = SUBJECTS[i].hex = light --sub-<id>).
Queries (index-free): notes = one `date` range; pnotes = owner == uid. Adapter: `watch('notes',cb,{range:[a,b]})`, `watch('pnotes',cb,{owner})`, `notesBetween(a,b)`.
Permissions: can('postNote') teacher/admin/dev; can('myNote') any member (guest no). Edit/delete class note: creator or admin/dev (`canEditNote(note)`). `by` immutable (rules).
## Contracts
- dates.js: todayKey() keyToDate(key) addDays(key,n) diffDays(a,b)=b-a fmtDay(key)->"T4 28/10" relText(diff); extra isKey(key).
- data.js: watchClass(cb) (one shared listener today-30d..+90d, cb gets the WHOLE cache incl. loaded ranges), watchMine(cb), loadClassRange(from,to)->Promise<note[]> (merges into cache, re-notifies watchers), saveClassNote(note), deleteClassNote(id), saveMine(note), deleteMine(id), newNoteId(); extra inLive(key), canEditNote(note). save* strip `id`; saveMine sets owner=uid and slot=count if slot null. Outside the live window saves/deletes update the cache by hand.
- layout.js: layoutSlots({classNotes,mine,cols,minSlots})->[{slot,note|null,kind:'class'|'mine'|'empty'}] (class by `at` in first slots, mine at slot or next free, whole rows, >=minSlots, >=2 free); resetMine({classNotes,mine})->[{id,slot}] by `at`, free slots after class notes. Both pure; give them ONE day's notes.
- board.js: createBoard({onOpen, onMove?(moves:[{note,slot}])}) -> {el, update({dateKey,classNotes,mine}), destroy()}; with onMove only kind 'mine' cards (.nb-drag) drag: mouse 4px, touch/pen 250ms long-press, keyboard Enter/Space pick up, arrows, Enter drop (same slot = open detail), Esc cancel; free slot = move, personal = swap, class = snap back + shake; paint is deferred while dragging; update takes any notes and filters n.date===dateKey itself. Columns 2/3/4 by board width (<500/<800), ResizeObserver. Also exports noteCard(note,kind,{onOpen}), tiltOf(id).
- sheet.js: openNoteSheet({mode:'class'|'mine', note?, dateKey}) / openNoteDetail(note) (mine = note.owner set). Both return openSheet handle.
- subjects.js: SUBJECTS[{id,name,hex}], subjectOf(id) (fallback khac), noteStyle(note,kind)->{cls,style}, textOn(hex), contrast(a,b), HEX.
- calendar.js: createCalendar({getSelected,getToday,onSelect(key),marksFor(key)->[{color,kind:'class'|'mine'}], onRange?(from,to)}) -> {el,update(),destroy()}. Monday-first; compact = month label + selected-week strip, tap = month grid (roving tabindex, arrows/PageUp/PageDown, Esc/outside/focus-out close, 'Hôm nay' button). >=900px: overlay card over a fixed-height host; <900px: in flow, grid-rows animation. onRange fires when the visible range changes (index uses it for loadClassRange). Exports dotsOf(marks): <=3 class dots (distinct colours first), '+' when more, one hollow ring for personal.
- agenda.js: createAgenda({getNotes(from,to)->note[] (class + own personal, personal has .owner), onOpen(note), onDay?(key)}) -> {el,update(),destroy()}; 'Tiếp theo' card (nearest class note today..+90d), chips 7 ngày tới / Tuần này / Tuần sau / Cả tháng (today..month end), grouped list. Phones: collapsible, open by default only when something is due today/tomorrow until the user toggles; >=900px always open in the right column under the calendar. Exports rangeOf(range,todayKey), barColor(note).
## index.js
Header = `.nb-hdr`: `.nb-hl` (h1 + banner pill `.nb-pill` + add actions) and the calendar. Pill: today 'Hôm nay · T6 24/10' (disabled); otherwise 'Note của T4 28/10 · còn 4 ngày' with icon `today`, tap -> back to today (+ `.nb-ret` animation). Under it `.nb-layout`: agenda + `.nb-main` (`.nb-nav` prev/label/next + 'Sắp lại' + board). State: key, cls, mine, `ovr` (optimistic slots id->slot until the listener confirms/fails/4s). `go(key)` = set + paint; loading of other months is driven by calendar onRange -> ensure() (loadClassRange, retry after 15s on failure, empty state offers 'Thử lại'). Moves/reset = applyMoves(): optimistic, ONE saveMine per moved note, errors -> toast(errMsg) + revert. 'Sắp lại' = resetMine for the day's personal notes (only changed ones written) + toast 'Hoàn tác'. Phone '+' is `.nb-fab` on document.body (removed in destroy).
